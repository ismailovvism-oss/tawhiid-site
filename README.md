# Сайт tawhiid.com

Корень домена: главная страница + база знаний из вольта Obsidian.
Библиотека-читалка живёт отдельно (`/kutub`, репозиторий `biblioteka-tawhid`)
и этим репозиторием не трогается.

```
главная/index.html   главная страница — правится руками, никакой CMS
главная/.htaccess    правило «нет файла — попробуй .html» для ссылок Quartz
главная-базы.md      первая страница базы знаний
quartz.config.yaml   настройка Quartz (имя сайта, язык, baseUrl, плагины)
собрать.sh           собирает всё в выкладка/
выкладка/            то, что уезжает на хостинг (index.html + ilm/)
```

## Сборка

Генератор в репозитории не хранится, ставится один раз:

```bash
git clone --depth 1 https://github.com/jackyzha0/quartz.git quartz
cd quartz && npm install && cd ..
```

Дальше — одна команда:

```bash
./собрать.sh
```

Она копирует `~/obsid/alqasawi/Ислам` в `quartz/content`, собирает Quartz в
`выкладка/ilm` и кладёт сверху главную.

## Что попадает на сайт

Только заметки с `publish: true` во фронтматтере — за это отвечает плагин
`explicit-publish`. Забыл пометить — заметка не вышла; это безопаснее обратного
правила, потому что в вольте есть личные разделы.

## Выкладка

`git push` в master → на хостинге cron раз в десять минут тянет репозиторий и
синхронит `выкладка/` в `~/public_html/`, не трогая `kutub`, `.well-known` и
`cgi-bin`. Скрипт на сервере — `~/bin/deploy-site.sh`.
